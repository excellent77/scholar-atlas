## 使用者驗收清單
1. 建立新資料父目錄並授權，確認 scholar-atlas-data/workspace.json 出現。
2. 新增教授，確認 profile.json；加入兩份文字型 PDF，確認 original.pdf 與 pages.json。
3. 關閉再開啟網站，選原父目錄，確認論文仍在。
4. 設定金鑰並測試生成，逐篇分析；點引用核對 PDF 頁與逐字片段。
5. 產生跨篇概要；修改研究方向後，舊概要應標示需更新。
6. 匯出 ZIP 並解壓，確認包含真實 PDF、文字與分析；封存後資料應移至 trash。
