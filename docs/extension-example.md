# 交給下一個 AI 的延伸任務範例

請先閱讀 AGENTS.md，新增「閱讀路線」頁籤。

需求：針對已選教授，把待讀論文按年份由舊到新排序，閱讀中的論文置於最前；已讀論文另列。顯示標題、年份、閱讀層級與來源。頁面明確說明排序只是規則建議。不要更動原始論文陣列或自動改變閱讀狀態。

實作：core.js 新增 readingOrder，app.js 既有 tabs 加入閱讀路線；重用 panel 與 paper 樣式。不得重新建立另一份論文儲存。測試空資料、同年論文與已讀分類，更新 README 並執行 npm test 和 npm run build。

驗收：新增論文後新頁立即反映；原本的 PDF、概要、備份仍可用；手機單欄無水平溢出。
