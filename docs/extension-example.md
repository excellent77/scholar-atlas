# 可重複的延伸任務

請閱讀 AGENTS.md，新增「方法比較」頁。

1. 重用 Professor、Paper 與 Claim，讀取選取教授的已保存 analysis.json。
2. 以 method 為比較項，顯示論文名、年份、原文整理或推論標籤與所有 citations。
3. 引用沿用 evidence 原文檢視，不能只顯示不可點的參考文獻。
4. 缺少分析時提供分析入口，不用標題或關鍵字生成假結論。
5. 若原文 hash 改變拒絕使用舊分析；新增缺失檔、錯誤頁碼與空資料測試。
6. 不能新增 API key 持久化、模擬模型或公開範例教授。
7. 更新文件，npm run build、npm test、瀏覽器驗證。
